# Historical material

These files preserve earlier development work and are not the main simulator entry points.

- `legacy_city_generators/`: alternative attribute, nDSM, and OSM-level height strategies.
- `diagnostics/`: original mesh, Earth Engine, AOD, and analysis inspection utilities. Some names were clarified; source behavior is retained.
- `analysis/`: historical publication-figure and mentor-report generators. These need the missing original full-city NPZ files and expect relative paths in their working directory.
- `incomplete_pipeline/aoi.py.txt`: verbatim incomplete pipeline source, including its duplicated block and missing helper dependency.
- `config-original.yaml`: original simulator configuration for reference. Its relative paths apply to the old folder layout.
- `gitignore-original.txt`: original simulator ignore rules, retained for reference.

Use the root README, `configs/`, and `src/pasa/` for the runnable organized project.
